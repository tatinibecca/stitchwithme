# Stitchwithme

App web responsivo (PWA) para um casal gerenciar a casa. O MVP cobre o módulo **Finanças**.

- Especificação: [`docs/PRD.md`](docs/PRD.md)
- Instruções do projeto e regras: [`CLAUDE.md`](CLAUDE.md)
- Decisões: [`docs/DECISIONS.md`](docs/DECISIONS.md)
- Tokens e componentes: rode o app e abra `/design-system`

## Comandos

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm test           # Vitest (inclui o teste de contraste WCAG dos tokens)
npm run build
```

Requer Node 22 ou superior.
